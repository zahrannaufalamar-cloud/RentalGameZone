# 🎮 Rental GameZone

## 📌 Deskripsi Proyek

**Rental GameZone** adalah aplikasi berbasis Java Console yang dibuat untuk membantu petugas rental PlayStation dalam menghitung biaya penyewaan dan menampilkan rincian pembayaran pelanggan. Aplikasi ini dikembangkan menggunakan bahasa pemrograman Java melalui IDE NetBeans sebagai latihan praktikum Pemrograman Java Dasar.

Aplikasi ini menyediakan dua pilihan konsol, yaitu PlayStation 4 (PS4) dan PlayStation 5 (PS5), dengan tarif sewa yang berbeda. Program juga dilengkapi dengan fitur diskon, tambahan minuman, serta struk pembayaran secara otomatis.

## ✨ Fitur Aplikasi

- **Input Data Pelanggan:** Memasukkan nama pelanggan.
- **Pilihan Konsol:** Memilih PlayStation 4 atau PlayStation 5.
- **Perhitungan Biaya Sewa:** Menghitung biaya berdasarkan durasi bermain.
- **Diskon Otomatis:** Mendapatkan diskon 10% jika durasi bermain minimal 3 jam.
- **Tambahan Minuman:** Pilihan membeli minuman seharga Rp5.000.
- **Struk Pembayaran:** Menampilkan rincian biaya sewa, diskon, biaya minuman, dan total pembayaran.
- **Transaksi Baru:** Memungkinkan pengguna melakukan transaksi berulang tanpa menjalankan ulang aplikasi.

## 💰 Daftar Harga

| Jenis Konsol | Harga per Jam |
|---|---:|
| PlayStation 4 (PS4) | Rp8.000 |
| PlayStation 5 (PS5) | Rp12.000 |
| Tambahan Minuman | Rp5.000 |

**Ketentuan diskon:** Pelanggan mendapatkan diskon sebesar 10% dari biaya sewa apabila bermain selama minimal 3 jam.

## 🛠️ Teknologi yang Digunakan

- Bahasa pemrograman Java
- Apache NetBeans IDE
- Java Console
- Scanner untuk input pengguna

## ▶️ Cara Menjalankan Aplikasi

1. Buka proyek Rental GameZone di Apache NetBeans.
2. Pastikan Java Development Kit (JDK) sudah terpasang.
3. Buka file Java yang berisi method `main()`.
4. Klik **Run Project** atau tekan `F6`.
5. Masukkan nama pelanggan.
6. Pilih konsol yang akan disewa.
7. Masukkan durasi bermain.
8. Tentukan apakah ingin menambahkan minuman.
9. Lihat struk pembayaran yang ditampilkan pada jendela Output.
